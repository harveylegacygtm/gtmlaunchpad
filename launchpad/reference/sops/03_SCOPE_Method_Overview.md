The course teaches them **Scale first, then bottom-up** - E → P → O → C.

## The five letters

- **S - Scale.** The math layer. Revenue goal → email volume → infrastructure cost. → **SOP 04**

- **C - Copy.** The messaging layer. Frameworks, tone, sequence structure, subject lines, sentiment analysis. → **SOP 09**

- **O - Offer.** The product layer. Core offer, lead magnets, market sophistication, value ladder. → **SOP 07**

- **P - Prospect.** The targeting layer. ICP mapping, multi-source list building, enrichment, scoring. → **SOP 06** (ICP) and **SOP 10** (Lead List Building)

- **E - Email Deliverability.** The infrastructure layer. Domains, inboxes, DNS, warmup, reputation. → **SOP 05**

## The order matters - bottom-up

The letters spell SCOPE so you remember them. The order of *importance* runs in reverse:

- **E - Email Deliverability** ← most important. Without this, nothing works.

- **P - Prospect**

- **O - Offer**

- **C - Copy**

- **S - Scale** ← least important. Math doesn't matter without the rest.

This bottom-up order is also how the course teaches it (after Scale): you build from the foundation up. Each layer depends on the one below it. 

Scaling broken copy just sends bad emails to more people. Clever copy can't sell a bad offer to the wrong person. The best offer to the wrong audience doesn't convert. And the perfect email to the perfect prospect doesn't matter if it lands in spam.

## How to use SCOPE

**Pattern 1 - Learning the Playbook.** Scale first, then bottom-up. 

Read the SOPs in order: **04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 12 → 13.**

Why Scale first? Because you should see the whole picture - how outbound generates predictable revenue and fast ROI - before you build any single piece. After that, you build from the foundation up: deliverability, then prospects, then offer, then copy. 

Each SOP builds on the ones before it.

**Pattern 2 - Diagnosing a campaign that isn't working.** Walk SCOPE bottom-up:

- **Email Deliverability healthy?** Bounce rate normal? Reply rate vs. baseline? - If broken, fix here. Stop everything else.

- **Prospect right?** Reaching the right people? Qualification rate normal? - If broken, fix the list before anything else.

- **Offer right?** Value prop relevant? Positive replies coming through? - If broken, fix the offer.

- **Copy doing the work?** Opens, reads, replies? - If broken, fix the copy.

- **Scale appropriate?** Sent enough to draw conclusions? - If under 1,000 contacts, send more before optimizing anything.

This is the diagnostic flow from **SOP 11** in short form. Memorize the order - it saves you from spending three weeks tweaking copy when the real problem is a bad list.
